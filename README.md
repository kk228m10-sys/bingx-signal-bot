# BingX Signal Bot

Telegram-бот, который после закрытия каждой 15-минутной свечи проверяет фьючерсы
BingX и присылает план сделки: направление, вход, стоп, три тейка, объём под
депозит и риск, примерную ликвидацию. Потом сам следит за сигналом и пишет,
когда взят тейк (и напоминает перенести стоп в безубыток) или сработал стоп.

**Бот ничего не покупает и не продаёт.** Он читает только публичные данные
BingX, ключ биржи ему не нужен. Сделки ставишь ты.

## Запуск

1. В `.env` — `BOT_TOKEN` (от @BotFather) и `ADMIN_ID` (твой Telegram ID).
   Образец — `.env.example`.
2. `python bot.py` или двойной клик по `start-console.bat`.
3. В Telegram: `/start`.

Нужен Python 3.10+, сторонних библиотек нет.

## Команды

| Команда | Что делает |
| --- | --- |
| `/now [монета]` | обзор: тренд по 1d/4h/1h, RSI, funding, OI, уровни |
| `/scan` | проверить сетапы прямо сейчас |
| `/open` | открытые сигналы |
| `/stats` | статистика всех сигналов в R и $ |
| `/watch`, `/add SOL`, `/remove SOL` | список монет (до 10) |
| `/balance 50`, `/risk 2`, `/leverage 20` | параметры расчёта объёма |
| `/pause`, `/resume` | выключить/включить новые сигналы |

Каждый день в 9:00 (по `TZ_OFFSET_HOURS`) — утренний обзор BTC.

## Как устроены сигналы

`signals.py`, параметры в `PARAMS`:

- **Отбой**: свеча-отбой (тень ≥ 40% диапазона) от сильного уровня — цены, где
  было несколько разворотов на 1h/4h.
- **Ретест**: пробой уровня на 1h с объёмом ≥ 1.5× среднего, затем возврат к
  уровню и удержание.
- Фильтры: тренд 1d+4h, RSI 1h, funding (перекос толпы), всплески волатильности.
- Стоп — за уровнем/тенью плюс запас в ATR. Тейки — чуть раньше следующих
  уровней. TP2 должен давать не меньше 1.5R после комиссий.
- Одна монета + направление — не чаще раза в 4 часа.

## Проверка на истории

```
python backtest.py BTC-USDT ETH-USDT SOL-USDT --days 30            # текущие правила
python backtest.py BTC-USDT ETH-USDT SOL-USDT --days 90 --grid     # подбор на 60д, проверка на последних 30д
python -m unittest discover -s tests                               # тесты расчётов
```

Бэктест считает вход по цене сигнала, комиссию тейкера, стоп первым при
неоднозначной свече, безубыток после TP1, закрытие через 72 часа.
Прошлый результат не гарантирует будущий.

## Файлы

- `bot.py` — Telegram, команды, расписание
- `signals.py` — сетапы, тейки, объём
- `tracker.py` — сопровождение сигналов и статистика
- `market.py` — данные BingX и индикаторы
- `backtest.py` — прогон правил по истории
- `data/state.json` — настройки, сигналы, статистика; `data/bot.log` — лог
